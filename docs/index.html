Account Guard

Daily limits on your real Upstox and Dhan accounts: −₹3,000 loss · +₹1,500 target.

Daily limit watcher

–

Reads your real Upstox P&L every minute (09:15–15:30). At the daily limit it locks NSE & BSE F&O with Upstox's Kill Switch (once you have no open F&O position) and unlocks it automatically the next trading morning. This 1-minute watcher only alerts and locks; exits are done by auto-protect below.

Auto-protect · Level 2

Your Oracle server (fixed IP) checks Upstox & Dhan every 5 seconds. It can only cancel pending F&O orders, exit existing F&O positions and set Dhan's P&L Exit — it never opens a trade.
